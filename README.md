DEADLOCK CHARACTER ROSTER

Descripción del proyecto
Este proyecto consiste en una página web inspirada en el videojuego Deadlock. Presenta seis espacios para personajes, cada uno con su nombre, rol y descripción.

Funcionalidades

Visualizar la información de los personajes.
Crear personajes personalizados agregando su nombre, rol y descripción.
Marcar personajes como favoritos.
Buscar personajes por nombre o rol.

Navegación
Explora los espacios disponibles para consultar la información de los personajes. Utiliza la función de búsqueda para encontrar personajes específicos, márcalos como favoritos o utiliza la opción de creación para agregar tus propios personajes a la página.

Objetivo
Desarrollar un roster interactivo de personajes que permita practicar conceptos de desarrollo web, manejo de información e interacción con el usuario.
