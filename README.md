DEADLOCK CHARACTER ROSTER

Descripción del proyecto
Este proyecto consiste en una página web inspirada en el videojuego Deadlock. Presenta seis espacios para personajes, cada uno con su nombre, rol y descripción.

Funcionalidades

Visualizar la información de los personajes.
Crear personajes personalizados agregando su nombre, rol y descripción.
Marcar personajes como favoritos.
Buscar personajes por nombre o rol.

Navegación
Explora los espacios disponibles para consultar la información de los personajes. Utiliza la función de búsqueda para encontrar personajes específicos, márcalos como favoritos o utiliza la opción de creación para agregar tus propios personajes a la página.

Objetivo
Desarrollar un roster interactivo de personajes que permita practicar conceptos de desarrollo web, manejo de información e interacción con el usuario.

Bitácora de decisiones 
-Propuse la funcionalidad de elegir favoritos en los héroes, dándoles un apartado extra en los que se pueden visualizar. 
-Si no existe un URL del render del héroe, sus iniciales se ponen en su lugar. Ocurre a la hora de crear un nuevo héroe ya que no pude añadir una opción de subir tu propio archivo IMG.
-Si un usuario entra a la URL de Github Pages no podrá ver los 6 personajes predeterminados, pero no podrá ver personajes que yo haya creado.
-Al añadir un nuevo personaje la pagina contiene todos los objetos dentro de un margen especifico para no desbordarse y darle un diseño mas estético
-Se utiliza un ID único para cada héroe ya que al momento de buscar se puede filtrar por nombre, ID o rol.
